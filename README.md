# ☕ JAVA ATM

An OOP-based ATM banking simulator built in Java. Runs in BlueJ or any Java terminal.

![Demo](demo.gif)

## ✨ Features
- Account creation with unique IDs
- Deposit & withdrawal with balance validation
- Full transaction history
- Object-oriented design (Encapsulation, Inheritance)

## 🚀 How to Run
1. Open the project in **BlueJ**
2. Right-click `Main` class → "void main(String[] args)"
3. Follow the on-screen prompts

## 🛠️ Built With
- Java 17
- OOP principles
- BlueJ IDE
